Funksjoner

Øv

En funksjon er en regel som forteller hvordan én verdi henger sammen med en annen.

  • En lineær funksjon kan skrives y = ax + b.
  • a er stigningstallet: hvor mye y øker når x øker med 1.
  • b er konstantleddet: der grafen krysser y-aksen.
  • En verditabell hjelper deg å tegne grafen punkt for punkt.
  • Hvis grafen går oppover mot høyre, er stigningstallet positivt. Går den nedover, er det negativt.

Viktige formler

Rett linje: y = ax + b a = stigningstall, b = konstantledd.
Stigningstall: endring i y / endring i x Fra (1,2) til (3,6): 4 / 2 = 2.

Vanlige feil

Å blande stigningstall og konstantledd.
Å sette punkter feil vei: x først, y etterpå.
Å tro at alle grafer må gå oppover.

Mini-eksempler med fasit

I y = 3x + 2, hva er stigningstallet?
3.
Hva blir y når x = 4 i y = 2x + 1?
y = 2 · 4 + 1 = 9.

Gjennomsnitt uten statistikkfunksjoner

Øv

Vi lager summen selv med en løkke og deler på hvor mange tall som er i listen.

data = [4, 6, 7, 9]
total = 0

for tall in data:
    total = total + tall

gjennomsnitt = total / len(data)
print(gjennomsnitt)

Median uten statistikkfunksjoner

Øv

Først sorterer vi listen. Så sjekker vi om antallet verdier er oddetall eller partall.

data = [9, 2, 7, 4, 10]
data.sort()

n = len(data)
midten = n // 2

if n % 2 == 1:
    median = data[midten]
else:
    median = (data[midten - 1] + data[midten]) / 2

print(median)

Enkel simulering av terningkast

Øv

Koden kaster en terning mange ganger og teller hvor ofte den får seks. Jo flere kast, jo nærmere kommer vi ofte den teoretiske sannsynligheten 1/6.

import random

antall_kast = 1000
seksere = 0

for i in range(antall_kast):
    kast = random.randint(1, 6)
    if kast == 6:
        seksere = seksere + 1

sannsynlighet = seksere / antall_kast
print(sannsynlighet)
